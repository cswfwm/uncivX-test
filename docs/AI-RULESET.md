# AI 规则集格式（`.cote`）

`.cote` 是 **JSON 文件换了一个后缀**，用后缀区分「这是配置」而不是普通存档。
用任意文本编辑器即可编写，也可以直接让 AI 生成一份。

放置位置：游戏数据目录下的 `rulesets/` 文件夹。
在「设置 → AI → AI 规则集」点「重新读取规则集」生效，点「生成示例文件」可得到一份可编辑的模板。

## 最小可用示例

```json
{
  "format": "cote",
  "version": 1,
  "name": "我的打法",
  "rules": [
    { "id": "rush", "text": "前 40 回合全力造兵，优先进攻最近的邻国。", "when": "earlyGame" }
  ]
}
```

## 完整示例

```json
{
  "format": "cote",
  "version": 1,
  "name": "稳健扩张",
  "description": "先发育后开战，交易以获利为先",
  "tendencies": {
    "aggression": 35,
    "expansion": 70,
    "diplomacy": 60,
    "tradeProfit": 65,
    "betrayal": 10,
    "militaryFocus": 45,
    "scienceFocus": 60
  },
  "rules": [
    { "id": "settle", "text": "前 60 回合优先生产开拓者，优先在有淡水的丘陵建城。", "when": "earlyGame" },
    { "id": "guard", "text": "首都始终保留至少一个军事单位驻守。", "when": "always" },
    { "id": "war", "text": "交战时把大部分产能给军事单位，暂停奇观。", "when": "atWar" }
  ]
}
```

## 字段说明

### 顶层

| 字段 | 必填 | 说明 |
|---|---|---|
| `format` | 是 | 固定写 `"cote"`，用于校验文件类型 |
| `version` | 是 | 当前只有 `1` |
| `name` | 是 | 规则集名称，会显示在设置页 |
| `description` | 否 | 一句话说明这份规则的思路 |
| `tendencies` | 否 | 七项倾向，见下表；不写则用默认值 50 |
| `rules` | 否 | 具体规则列表 |

### tendencies（倾向值）

每项取值 **0–100**，越高表示越偏向该方向。

| 键 | 含义 | 低值效果 | 高值效果 |
|---|---|---|---|
| `aggression` | 进攻性 | 龟缩防守 | 主动寻找战机 |
| `expansion` | 扩张 | 只求守住现有城市 | 全力铺城抢地 |
| `diplomacy` | 外交接触 | 少谈判 | 主动签协定、结盟 |
| `tradeProfit` | 交易抬价 | 见好就收 | 极限压价、争取更多回报 |
| `betrayal` | 毁约倾向 | 严守承诺 | 为利益可背弃协议 |
| `militaryFocus` | 军事优先 | 建筑优先 | 造兵优先 |
| `scienceFocus` | 科研优先 | 不刻意堆科研 | 优先科研建筑与科技 |

### rules（规则条目）

| 字段 | 必填 | 说明 |
|---|---|---|
| `id` | 是 | 唯一标识，不能重复，建议用英文短横线命名 |
| `text` | 是 | 给模型读的一句话，写成具体动作而不是空泛目标 |
| `when` | 否 | 生效条件，不写表示任何情况都生效 |

`when` 可选值：

| 值 | 触发时机 |
|---|---|
| `always` | 任何情况 |
| `earlyGame` | 前 60 回合 |
| `atWar` | 正在交战 |
| `happinessNegative` | 幸福度为负 |
| `goldNegative` | 金币收入为负 |
| `fewCities` | 城市数少于 3 |

## 书写建议

- `text` 写成可执行的动作，例如「优先在有淡水的位置建城」，不要写「发展得更好」。
- 一条规则只讲一件事，需要多条就写多条。
- 条件明确的规则放在前面，通用规则放后面。
- 规则会追加在内置规则之后，与内置规则冲突时以你的规则为准。

## 校验规则

加载时检查以下项，不通过会提示原因且不生效：

- `format` 必须是 `cote`
- `version` 必须是 1
- `id` 不能重复
- `when` 必须是上表列出的值

## 让 AI 帮你写

可以直接在「AI 指导」里说：

> 帮我写一份 .cote 规则集，打法偏防守反击，前期稳发育，被打时才反扑，交易尽量压价。

AI 会按本格式输出，你保存成 `.cote` 文件放进 `rulesets/` 文件夹，再回设置里读取即可。
